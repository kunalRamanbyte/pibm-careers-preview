# PIBM Careers Design Preview

A responsive, self-contained careers website prototype with illustrative roles, member stories, faculty imagery and an application preview.

## GitHub Pages

Publish the `main` branch from the repository root. `index.html` contains all styles, scripts, fonts and images; no build step is required.

## Preview status

The listed roles and member testimonials are illustrative. The application form does not upload CVs, store applications or submit information to PIBM.

Faculty portraits and institutional information are attributed to PIBM’s official website within the page. The embedded Inter font license is included in the HTML.
